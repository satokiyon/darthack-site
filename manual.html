DartHack 操作マニュアル

基本操作からカスタマイズ・最新機能まで網羅した公式ユーザーガイド

トップページへ戻る English Manual プライバシーポリシー

DartHack は、名作ローグライクゲーム NetHack 5.0（日本語版 NetHackJP および英語版 NetHack 本家コア）をスマートフォンやタブレットで快適にプレイできるよう Flutter/Dart で構築したアプリです。 このマニュアルでは、タイトル画面の起動から基本の冒険操作、画面上のタップ・キーボード・物理キー操作、さらにタイルセット・フォント・UI配置・サウンド・縛りプレイ・defaults.nh 編集などの詳細設定までを、実際のゲーム画面（番号付き枠線付き）とあわせて解説します。

画面はタップ・ドラッグ・ピンチ操作に対応しています。また、ハードウェア（物理）キーボードを接続した状態でのキーボード操作もサポートしています。

1 アプリ起動とタイトル画面

アプリを起動すると、最初にタイトル画面が表示されます。冒険を始める前の言語切替やゲーム設定、説明書・攻略情報の閲覧をここから行えます。

図 1-1: タイトル画面の各ボタン構成
  1. 1遊び方・ガイドブック: NetHack の公式ガイドブック（遊び方や基本ルール）をアプリ内で開きます。ゲーム開始前でも読めるため、初めてプレイする際の確認に便利です。
  2. 2スポイラー（攻略情報）: ゲームの仕様やアイテム効果・モンスター情報などの攻略資料（NetHack スポイラー）を閲覧できます。
  3. 3DartHack マニュアル: この DartHack ユーザーマニュアルをアプリ内でオフライン閲覧できます。
  4. 4詳細ゲーム設定: タイルセット・フォント・画面レイアウト・サウンド・defaults.nh などの詳細設定画面を開きます。
  5. 5表示言語の切替（日本語 / English）: ボタンをタップして 日本語（NetHackJP コア） と English（NetHack オリジナルコア） を切り替えます。タイトル画面およびゲーム全体のUI・エンジン言語が切り替わります。
  6. 6冒険を始める: キャラクター作成（名前の入力）および既存セーブデータの再開ダイアログへ進みます。
遊びたい言語（日本語または英語）をタイトル画面で選んでから「冒険を始める」を押してください。

2 キャラクター作成と冒険の開始

「冒険を始める」をタップすると、プレイヤー名とプレイモードを指定する「お名前は？」ダイアログが表示されます。

図 2-1: 名前入力・セーブデータ選択・プレイモード選択ダイアログ
  1. 1キャラクター名の入力: 冒険者の名前を入力します（UTF-8 で最大 31 バイトまで）。入力した名前で新規作成またはセーブデータの検索が行われます。
  2. 2既存のセーブデータ: すでに途中で中断セーブしているキャラクターがいる場合、リストに表示されます。タップして選ぶと、入力欄に名前が自動セットされ続きから再開できます。
  3. 3プレイモード切替（通常 / 探索 / ウィザード）: ゲームの遊び方（3種類のモード）を選択します。
  4. 4選択中モードの説明欄: 現在選んでいるプレイモードのルールと注意点が表示されます。
  5. 5ゲーム開始 / キャンセル: 「ゲーム開始」をタップするとプロンプト入力を確定して冒険へ進みます（新規作成時はチュートリアル選択や職業・種族選択、またはランダム生成が続きます）。

3 メインゲーム画面の全体構成

冒険が始まると、上下または全体を使ったメインプレイ画面が表示されます。初期配置（レイアウトパターン1）では上から ステータス → メッセージ → マップ → 操作パッド → コマンドパネル の順に並びます。

図 3-1: メインゲーム画面（レイアウトパターン1・パネル折りたたみ時）
  1. 1ステータス表示エリア: キャラクター名・称号、能力値（筋力/器用/耐久/知力/賢明/魅力）、属性（秩序/中立/混沌）、現在階層・所持金 $・HP・魔力・防御力(AC)・経験レベル・経過ターン数などを表示します。hitpointbar 有効時は背景にHPゲージも表示されます。ステータス領域をタップすると能力値や耐性などのステータス詳細（#attributes）が表示され、武器や防具（武器: / 防具: など）をタップ（またはステータス領域を長押し）すると装備一覧（#seeall）を確認できます。
  2. 2メッセージ表示エリア: ゲーム内の行動結果やモンスターの攻撃・発見メッセージが表示されます。タップすると「メッセージ履歴」シートを開いて過去のログをさかのぼれます。
  3. 3ダンジョンマップ表示エリア: 現在探索中のダンジョンを表示します。ドラッグで視点を動かし、ピンチイン／ピンチアウトで自由に拡大・縮小できます。マスをタップすると位置に応じた行動メニューが開きます。
  4. 4半透明メニューボタン（左）: タップすると「DartHack メニュー」（第8章）を開きます。画面右端や左端など、設定で配置を変更できます。
  5. 5全体マップボタン（右）: タップすると現在の階層の全体を見渡せる「階層の全体地図」ダイアログ（第4章）を開きます。
  6. 68方向移動パッド＋移動モード切替: 周囲の8つの菱形ボタン（y k u / h . l / b j n）で8方向へ移動・攻撃します。中央のボタン（初期状態は「標準」）をタップすると登録済みの移動モードを順番に切り替えられ（方向入力待ち中は . を送信）、長押しすると「使用する移動モードの選択」ダイアログ（ダッシュ等）を開きます。
  7. 73×3 クイックショートカット: 使用頻度の高い9個のコマンド（初期設定では「持ち物」「調べる」「拾う」「そこ」「ここ」「会話」「食べる」「再実行」「Esc」）を1タップで実行できるグリッドです。各ボタンを長押しすると、ボタンに割り当てるキー・コマンドと表示ラベルをその場で変更できます。
  8. 8コマンドパネル＆展開ハンドル: よく使う行動ボタンをカテゴリ別リストにまとめた下部バーです。現在選択中のパネル内容が1行で表示され、上部のハンドルをタップまたは上スワイプすると全パネルを展開できます。また、パネル上の各ボタンを長押しすると、ボタンの追加・削除や割り当てキー・ラベルの変更を行えます。

コマンドパネルの全展開表示

コマンドパネルのハンドル（1）を上方向へスワイプまたはタップすると、登録されているすべてのパネルが縦に展開されます。

図 3-2: 下部コマンドパネルを全展開した状態
  1. 1折りたたみ・展開ハンドル: タップまたは下方向へスワイプすると、再び1行のコンパクト表示へ戻ります。
  2. 2標準パネル: 左端の [kbd]（または [pad]）ボタンでソフトキーボード表示と移動パッド表示を切り替えます。#（拡張コマンド）、20探索、待機、足元、遠見、置く、飲む、投げるなど基本行動が並びます。
  3. 3戦闘パネル: 投げる、射撃、矢筒、読む、杖、詠唱、呪文、蹴る、持ち替など戦闘寄りのコマンドを集めたパネルです。
  4. 4道具パネル: 持ち物、使用、拾う、置く、複数置、あさる、飲む、読む、浸すなどアイテム操作に特化したパネルです。
  5. 5情報パネル: ヘルプ、コマンド、調べる、遠見、足元、属性、呪文、発見品、実績など情報確認用コマンドをまとめています。
左端のパネル名ボタン（例：「標準」「戦闘」など）をタップしてパネルを直接切り替えたり、横スクロールで隠れている右側のボタンを使ったりできます。パネル上の各ボタンを長押しするとその場でボタンの追加・削除やキー・ラベルの変更ができ、「詳細ゲーム設定 → カスタムコマンドパネル編集」（第15章）からもパネル構成をまとめて編集できます。

コマンドパネルの長押しカスタマイズ

コマンドパネル上の編集したいボタン（例：20探索 など）を長押しすると、「ボタン編集」ダイアログが開き、設定画面を開かなくてもその場でカスタマイズできます。

図 3-3: コマンドパネルのボタンを長押しして開くボタン編集メニュー
  1. 1編集対象ヘッダー: 長押ししたボタンの現在割り当てられているコマンド（例：ボタン編集: 20s）を表示します。
  2. 2コマンド・ラベル変更: 「コマンドを変更」で実行するキーやコマンド（例：20s, w, #pray）を書き換え、「表示ラベルを変更」でボタン上の表示名を変更できます（未設定時はコマンド名を表示）。
  3. 3ボタンの挿入: 「前にボタンを追加」「後にボタンを追加」で、選択したボタンの前後へ新しいボタンを追加します。
  4. 4削除・初期化: 「ボタンを削除」でそのボタンを取り除き、「パネルをデフォルトに戻す」で選択中のパネルを初期状態へリセットします。
  5. 5キャンセル: 変更を行わずにダイアログを閉じます。

ボタン表示形式の切り替え（コマンドそのまま表示）

「詳細ゲーム設定 → 操作コントローラ設定 → ボタン表示形式」（第14章）を 「コマンドをそのまま表示」 に設定すると、ボタン上のラベル名（「持ち物」「調べる」「20探索」など）ではなく、実際に送信される入力コマンド（i, ;, 20s など）がそのままボタンに表示されます。

NetHack のキー操作にすでに慣れている方にとっては、どのキーコマンドが送信されるか一目で分かるため、この設定の方が分かりやすく快適に操作できます。

図 3-4: 「コマンドをそのまま表示」に設定したときの 3×3 クイックショートカットとコマンドパネル
  1. 13×3 クイックショートカット（コマンド表記）: 「持ち物」「調べる」「会話」などのラベルが、実際のキーコマンド（i, /, ,, #ther..., #chat, e, ^a 等）で表示されます。
  2. 2コマンドパネル（コマンド表記）: 下部の各コマンドパネル上のボタンも、20s, ., :, ;, d, q のようなコマンドそのままの表記に切り替わります。

4 移動操作・マップタップ・全体マップ

移動モードの切り替え

8方向移動パッド中央のボタン（「標準」など）を長押しすると、「使用する移動モードの選択」ダイアログが開きます。ここで一時的な移動モードや常時オプション（F）を切り替えられます（中央ボタンを短くタップすると、有効化されている移動モードを順番に切り替えられます）。

図 4-1: 使用する移動モードの選択ダイアログ
  1. 1ダイアログ見出し: 使用する移動モードを選択する画面です。
  2. 2標準（1マス移動）: yuhjklbn による通常の1歩移動に戻します。
  3. 3長距離移動系（大文字 / g / G / ^(Ctrl)）: 壁や扉にぶつかるまで走る 大文字 (YUHJKLBN)、興味深いものが見つかるまで進む g<dir>（分岐で停止）、分岐を無視して進み続ける G<dir> / ^<dir> の4種から選べます。
  4. 4m モード（m<dir>）: 足元のアイテムを拾わずに移動したり、トラップや水・溶岩などの危険地形（自己責任）へ踏み込んだりしたいときに選びます。
  5. 5F モード（F<dir>）: 見えていない・感知していないモンスターがいると思われる方向へ強制的に攻撃します（透明な敵や暗闇での戦闘に有効）。チェックを入れると設定が維持されます。
  6. 6キャンセル / OK: 変更を確定して画面へ戻ります。

マップの直接タップ操作（コンテキストメニュー）

ダンジョンマップ上のマスをタップすると、タップした場所（自分の足元・隣接8マス・離れた場所）に応じた行動メニューが自動で開きます。

図 4-2: 足元・周辺マスをタップしたときの行動メニュー例
  1. 1メニュー見出し: 選んだ位置に対して実行する行動の選択プロンプト（「何をしますか？」など）です。
  2. 2文脈に応じたアクション一覧: 足元をタップ時は「階段を上る」「持ち物を見る」「周囲を探す」「ここで祈る」等、隣接マスをタップ時は「ここに移動する」や扉の開閉・攻撃・会話、離れたマスでは遠見やその方向への移動候補が提示されます。
  3. 3キャンセルボタン: メニューを閉じてマップへ戻ります。

全体マップ表示

画面右側の半透明マップボタン（または F9 / Alt-z キー）を押すと、現在の階層全体を見渡す「階層の全体地図」ダイアログが開きます。

図 4-3: 現在の階層全体を確認できる全体地図ダイアログ
  1. 1ヘッダーと閉じるボタン (×): 右上の × をタップするか、下のマップ領域外・Esc キーで閉じます。
  2. 2階層全体ビュー: これまで探索して記憶している部屋・通路・階段・祭壇などの全体像が描画されます。ドラッグでスクロールできます。
  3. 3ピンチズーム案内: 2本指でのピンチイン／ピンチアウトで全体図の拡大率を細かく調整できます。

5 ソフトキーボード・文字入力・拡張コマンド

ソフトキーボード（フルキーボード）

コマンドパネル左側の [kbd] ボタンをタップすると、移動パッド＋ショートカットの代わりに英字フルキーボードが表示されます。アルファベットのコマンド（例：q 飲む、r 読む、t 投げるなど）を直接打ちたいときや、Ctrl 修飾が必要な操作に最適です。

図 5-1: ソフトキーボード表示（フルキーボード）
  1. 1QWERTY キー配列部: q〜p / a〜l / z〜m と Shift（大文字切替）、Del キーを配置しています。
  2. 2修飾・特殊記号バー: ?123（数字・記号パネル切替）、Meta（Alt/Meta 修飾：階段探索や全体マップ等）、<、>（上り階段・下り階段）、:（足元を見る）、,（拾う）、Ctrl（コントロール修飾：Ctrl+x 等）、Enter を素早く入力できます。
  3. 3[Pad] 切替ボタン: タップするとソフトキーボードを閉じて、元の「8方向移動パッド＋3×3ショートカット」表示へ戻ります。
  4. 4コマンドパネル一覧: キーボード展開中でも、標準・戦闘・道具・情報パネルの各コマンドを組み合わせて利用できます。

拡張コマンド（# コマンド一覧）

コマンドパネルの # をタップ（またはキーボードで # を入力）すると、すべての拡張コマンド一覧ダイアログが開きます。NetHack 特有の複雑なコマンドをうろ覚えのまま探せる強力な機能です。

図 5-2: 日本語説明・絞り込み検索付きの拡張コマンドダイアログ
  1. 1絞り込み検索欄: コマンド名の一部（adjust, pray, loot 等）や説明キーワードを入力すると、候補をリアルタイムで絞り込めます。
  2. 2拡張コマンドリスト: アルファベット記号（a, b, c...）と #command 名、および動作解説が表示されます。行をタップするだけで直接実行できます。
  3. 3キャンセルボタン: 拡張コマンドを実行せずに閉じます。

6 アイテム操作メニューと名付け・文字入力プロンプト

アイテム選択メニュー

持ち物一覧（i）や装備（W/w）、飲む（q）、読む（r）などのアイテム選択時には、タイル画像付きの分かりやすいカテゴリ分けメニューが表示されます。

図 6-1: 武器・防具・食べ物などカテゴリ分けされたアイテム選択メニュー
  1. 1カテゴリ見出し: 「武器」「防具」「食べ物」などのカテゴリ見出しが黄色い枠で区分けされ、目的のアイテムをすぐに見つけられます。
  2. 2アイテム行（アイコン＆状態カラー）: 各行に割り当て文字（a, b, c...）とタイルアイコン、アイテム名、数量や装備状態（右手に装備中 / 装備中 / 予備武器 など）が表示されます。祝福・無祝福・呪い状態が文字色で視認しやすくなっています。
  3. 3キャンセルボタン: 選択を取り消してゲーム画面に戻ります。

テキスト入力・名付けプロンプト

アイテムに名前を付ける（#name / C）ときや、願い事・階層の注釈・金額入力などでは専用のテキスト入力ダイアログが開きます。

A.16 危険行動の確認 (Paranoid Confirm)

  • 否定・中止の入力例: no, ｎｏ, いいえ, やめる, 中止、キャンセル、Esc、または空のまま決定
  • 誤操作による死亡を防ぐため、完全な単語入力のみを肯定として受け付け、全角や日本語の「はい」も安全に利用できます。

A.17 所持品アイテムの文字選択 (Inventory Selection)

所持品から使用するアイテムを選ぶ際、文字（アルファベット）を入力するプロンプトです（例: どれを選択しますか? [a-z]）。

  • 入力例: a, ｂ, ｍ（メニュー表示）, ？（一覧表示）
  • 全角アルファベットや全角記号（？ や ＊）も自動的に半角へ正規化されて認識されます。

A.18 ステータス行のハイライト閾値設定 (Status Highlight Threshold)

#statuslines 設定画面や設定オプションにおいて、HPやMP、満腹度などのステータス警告カラーを切り替える閾値を設定する入力です。

  • 入力例: <50%, ＜５０％, =10, ＞＝２０
  • 全角の比較演算子（＜, ＞, ＝）や全角数字、全角パーセント（％）も半角に自動正規化されます。

B 付録: 日英両対応入力ガイド（ウィザードモード）

第2章の「お名前は？」ダイアログでプレイモードを ウィザード (Wizard) にしてゲームを開始した場合に利用できる、デバッグ・実験専用のコマンド入力シーンです（コマンドパネルの # 拡張コマンド一覧やソフトキーボード等から実行できます）。

B.1 階層テレポート (#wizlevelport)

全ダンジョンのあらゆる階層へ即座に移動できるコマンドです。

指定タイプ 日本語入力の例 英語入力の例 補足
特殊階層名 アストラル界 / モーロックの聖域 / 死者の谷 / 城 / ローディオス砦 / ヴラドの塔 astral / sanctum / valley / castle / fort / vlad 未訪問であっても、目的の階層へ直接テレポートできます。
クエスト階短縮指定 locate / goal / start / quest-1 locate / goal / start / quest-1 役割プレフィックス（val- 等）を省略した部分一致検索に対応しており、クエストの各階層へ簡単にジャンプできます。
全階層選択メニュー ? ? ダンジョン内の全ブランチおよび全階層が一覧メニューで表示され、対話的に選択できます。

B.2 アイテム生成 (#wish / Debug Wish)

制限のない自由なアイテム生成です。通常プレイと異なり、道具の複数個生成や強化値の制限解除、任意のアーティファクトの生成が可能です。

  • 入力例: 7個の魔法のマーカー, 祝福された+7虐殺の巻物, 7 magic markers, blessed +7 scroll of genocide

B.3 モンスター召喚 (#wizgenesis)

指定した任意のモンスターをその場で生成します。

  • 入力例: 銀色ドラゴン, マスター・リッチ, *（ランダム）, silver dragon, master lich

B.4 自由変身 (#polyself)

通常は変身が禁止されている種族（人間、NPC、ショップ店主、神官など）も含め、あらゆる存在に変身します。

  • 入力例: 長老, ショップ店主, クロイソス, aligned priest, shopkeeper, Croesus

B.5 玉座の効果指定 (#sit)

玉座に座った際に発生するイベント効果（全13種類）を任意に選んで発生させます。

  • 入力例: 1 〜 13, 0（ランダム）

B.6 経験レベル変更 (#level)

主人公の経験レベルを直接指定値に変更します。

  • 入力例: 1 〜 30

B.7 Luaスクリプト実行 (#wizlua / #wizdes)

外部の Lua スクリプトファイルやダンジョン定義（des）ファイルを動的に読み込んで実行します。

  • 入力例: test.lua, special_level.des

B.8 特定モンスターの生成 (create_particular)

ウィザードモードで特定のモンスター種族またはクラスを指定して召喚する際のプロンプトです。

  • 入力例: 銀色ドラゴン, silver dragon, L（リッチ類）, ＊（ランダム）
  • 全角文字（全角シンボルや全角モンスター名）も自動的に正規化されて認識されます。

B.9 変身形態の強制指定 (#wizforcechameleon)

カメレオンやドッペルゲンガーの変身先モンスターを指定するデバッグコマンドです。

  • 入力例: 銀色ドラゴン, silver dragon, d（犬類）, ランダム, random, *
  • 日本語の「ランダム」や全角記号も完全に対応しています。
