このプロジェクトについて

DartHack は NetHack の非公式な日本語化 + Flutter/Dart ポートです。 iOS / Android 向けの UI 実装を含みます。(現在はAndroidのみ)

特徴

  • NetHackをベースに、日本語化 + Flutter/Dart でモバイル向けに構築
  • iOS / Android のクロスプラットフォーム対応予定(現在はAndroid版のみ)
  • GUI レイアウトの柔軟なカスタマイズ
