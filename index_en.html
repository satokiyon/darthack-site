About This Project

DartHack is a Flutter/Dart mobile UI implementation for playing both the original NetHack and NetHackJP (unofficial Japanese localization of NetHack) on mobile devices.

Features

  • Mobile-friendly UI implemented in Flutter/Dart
  • Play the original NetHack in English
  • Play NetHackJP (unofficial Japanese localization of NetHack) in Japanese
  • Cross-platform iOS / Android / Windows support planned (currently Android only)
